# User Guide

Welcome! WordLevel is a Python project for analyzing how texts differ at the word level. The User Guide provides a detailed overview of how to work with the package's core data structures, compare texts using its declarative API, and produce publication-ready visualizations of your results.

## Getting started

The Quick Start guides cover how to [install the package](install.md) and get started making [comparisons](quick_start/make_a_comparison.md) and [word shift graphs](quick_start/make_a_word_shift_graph.md). You can see more examples in the [Cookbooks](cookbooks/constructing_catalogs.md), and learn more about the underlying [Concepts](concepts/corpora_and_catalogs.md).

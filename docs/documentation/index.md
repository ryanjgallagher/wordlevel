# User Guide

Welcome! WordLevel is a Python package for analyzing how texts differ at the word level. The user guide provides a detailed overview of how to work with the package's core data structures, compare them using its declarative API, and produce publication-ready visualizations of your results.

## Getting started

The Quick Start guides cover how to [install the package](install.md) and get up and running making [comparisons](quick_start/make_a_comparison.md) and [word shift graphs](quick_start/make_a_word_shift_graph.md). You can see more examples in the [Cookbooks](cookbooks/constructing_catalogs.md), and learn more about the underlying [Concepts](concepts/corpora_and_catalogs.md).

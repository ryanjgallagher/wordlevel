# API Reference

The API reference documents every public class, method, and configuration in WordLevel. It is
generated from the source, so it always describes the version you have installed.

Browse it from the navigation, which is organized by object: `Catalog` for building a catalog of
corpora and plotting it, `Comparison` for declaring a comparison, scoring it, and excluding tokens
from it, and `Lexicons` for loading a lexicon. `Configuration` and `Types` cover the objects those
methods take as arguments.

To learn the package task by task instead, start with the [User Guide](../index.md).
